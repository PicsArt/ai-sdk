Picsart AI SDK

One package to generate images, videos, and audio with 100+ AI models. Use it as a code library in your app or as a command-line tool in your terminal.

🖼
Images
Flux, Recraft, GPT Image, Gemini, and more
🎬
Videos
Kling, Sora, Luma, Hailuo, Veo, and more
🎵
Audio
ElevenLabs, OpenAI TTS, Gemini TTS
💡

Who is this for? Anyone at Picsart who wants to use AI generation — whether you write code, build prototypes, or just want to try models from your terminal.

Installation

You need Node.js 22+ installed on your computer. Then pick how you want to use it:

As a code library

Add it to your project so you can import it in your code.

terminal
npm install @picsart/ai-sdk

As a CLI tool

Install globally so the gen-ai command works anywhere in your terminal.

terminal
npm install -g @picsart/ai-sdk
✅

What's the difference? npm install (without -g) puts the package inside your project only. npm install -g installs it system-wide so the gen-ai terminal command works from any folder.

Quick Start

Here's the simplest possible example — generate an image in 4 lines of code:

Import the SDK

Pull in createClient (to connect) and Models (to pick a model).

your-script.ts
import { createClient, Models } from '@picsart/ai-sdk'

Create a client

The client is your connection to the Picsart API. You give it your authenticated fetch function and the API URL.

your-script.ts
const ai = createClient({
  fetch: myAuthenticatedFetch,
  apiUrl: 'https://api.picsart.com',
})
🔑

What is myAuthenticatedFetch? It's a function that makes HTTP requests with your Picsart login credentials attached. If you're inside the Picsart web app, the platform provides this for you. If you're writing a standalone script, ask your team for the auth setup.

Generate something!

Pick a model, write a prompt, and get back a URL to your generated image.

your-script.ts
const result = await ai.generate(Models.Flux2Pro, {
  prompt: 'a golden retriever surfing at sunset',
})

console.log(result.url)  // → https://...your-generated-image.png
🎉

That's it! The generate function sends your prompt, waits for the AI to finish, and gives you the result URL.

Full working example

example.ts
import { createClient, Models } from '@picsart/ai-sdk'

const ai = createClient({
  fetch: myAuthenticatedFetch,
  apiUrl: 'https://api.picsart.com',
})

// Generate an image
const image = await ai.generate(Models.Flux2Pro, {
  prompt: 'a cozy cabin in the mountains',
  aspectRatio: '16:9',
})

// Generate a video
const video = await ai.generate(Models.KlingV3Pro, {
  prompt: 'a timelapse of flowers blooming',
  duration: 5,
})

// Generate audio
const audio = await ai.generate(Models.ElevenV3, {
  prompt: 'Hello! Welcome to Picsart.',
  voiceId: 'aria',
})

console.log(image.url, video.url, audio.url)

Browsing Models

The SDK comes with 100+ AI models built in. The Models object lets you browse, search, and inspect them.

Interactive model catalog

Click a filter to see models of that type:

In your code

browsing models
// List all models
Models.list()

// Only video models
Models.list({ mode: 'video' })

// Search by name (case-insensitive)
Models.search('kling')
Models.search('flux')

// Access a specific model directly
Models.Flux2Pro            // Flux 2 Pro
Models.KlingV3Pro          // Kling 3.0 Pro
Models.Sora2               // Sora 2
Models.ElevenV3            // ElevenLabs v3

// Check model info
Models.Flux2Pro.name       // → "Flux 2 Pro"
Models.Flux2Pro.mode       // → "image"
Models.Flux2Pro.provider   // → "flux"

Generating Content

The generate method is the main way to create content. It takes a model and a params object, waits for the AI to finish, and returns the result.

Image generation

image
const result = await ai.generate(Models.Flux2Pro, {
  prompt: 'a minimalist logo for a coffee shop',
  aspectRatio: '1:1',
})

Video generation

video
const result = await ai.generate(Models.KlingV3Pro, {
  prompt: 'drone shot flying over a tropical beach',
  duration: 5,
  aspectRatio: '16:9',
})

Image-to-video (start from a picture)

image → video
const result = await ai.generate(Models.KlingV3Pro, {
  prompt: 'the person in the photo starts waving',
  imageUrls: ['https://example.com/my-photo.jpg'],
})

Audio / text-to-speech

audio
const result = await ai.generate(Models.ElevenV3, {
  prompt: 'Welcome to Picsart! Lets create something amazing.',
  voiceId: 'aria',
})

Estimate cost before generating

cost check
const credits = await ai.estimate(Models.Flux2Pro, {
  prompt: 'anything',
})
console.log(`This will cost ${credits} credits`)

Reading Results

When generate() finishes, it returns a result object. Here's what you get:

GenerateResult
url https://cdn.picsart.com/...result.png
model "flux-2-pro"
results [{ url: "https://..." }, ...]
drive { uid: "abc123", folder: { name: "AI Playground" } }
using the result
const result = await ai.generate(Models.Flux2Pro, {
  prompt: 'a sunset over the ocean',
})

// The main URL (shortcut to the first result)
result.url

// All results (some models return multiple)
result.results  // → [{ url: "..." }, { url: "..." }, ...]

// Which model made this
result.model   // → "flux-2-pro"

// Drive save info (if Drive is enabled)
result.drive   // → { uid: "...", folder: { name: "..." } }
📁

Auto-save to Drive: If you set up Drive when creating the client, every generation is automatically saved to your Picsart Drive folder. The result.drive field will contain the saved file info.

Model Parameters

Different models accept different parameters. The SDK helps you discover what each model supports:

discovering parameters
// Get the default values for a model
Models.getDefaults(Models.Flux2Pro)
// → { aspectRatio: "1:1" }

// Check if a model has a specific parameter
Models.hasParam(Models.KlingV3Pro, 'duration')   // → true
Models.hasParam(Models.Flux2Pro, 'duration')      // → false

// Get the options for an enum parameter
Models.getEnumOptions(Models.Flux2Pro, 'aspectRatio')
// → ["1:1", "16:9", "9:16", "4:3", "3:4", ...]

// Get range limits for a numeric parameter
Models.getRange(Models.KlingV3Pro, 'duration')
// → { min: 5, max: 10, step: 5, default: 5 }

// Check if a model accepts file inputs (images, video, audio)
Models.hasFileInput(Models.KlingV3Pro)  // → true (accepts images)
Models.hasFileInput(Models.Flux2Pro)    // → false (text only)

// Validate inputs before sending
Models.validate(Models.Flux2Pro, { prompt: 'hello' })
// → { valid: true }

Common parameters

ParameterTypeUsed byDescription
prompttextAlmost allWhat you want to generate
aspectRatiochoiceImage & VideoShape: "1:1", "16:9", "9:16", etc.
durationnumberVideoLength in seconds (usually 5 or 10)
imageUrlsfileImage & VideoSource image(s) for image-to-video or editing
voiceIdchoiceAudioWhich voice to use for speech
negativePrompttextSome imageWhat you do NOT want in the output
stylechoiceSome imageArt style preset
seednumberSome imageFixed seed for reproducible results

CLI Tool

The gen-ai command lets you generate content directly from your terminal — no code needed.

Getting started with the CLI

Install globally

terminal
npm install -g @picsart/ai-sdk

Log in

This opens your browser to authenticate with Picsart.

terminal
gen-ai login

Generate!

terminal
gen-ai generate -m flux-2-pro -p "a cat wearing sunglasses"

Or run gen-ai generate without flags to get an interactive menu where you can browse and pick a model.

CLI Commands

gen-ai pricingCheck how many credits a model costs

gen-ai configManage your saved settings
💡

Pro tip: Add -q (quiet) to suppress progress output, or --script for machine-readable JSON output. Great for piping into other tools.

Deep Links

Share pre-configured AI Playground sessions via URL. A deep link encodes the model, prompt, media inputs, and parameters into a compact query string.

💡

Deep links use DEFLATE compression + base64url encoding — even long prompts with multiple image URLs typically fit under 2KB.

Encode (create a payload)

import { encodeDeepLinkPayload } from '@picsart/ai-sdk'

const payload = encodeDeepLinkPayload('veo-3.1', {
  prompt: 'A cinematic sunset over the ocean',
  aspectRatio: '9:16',
})
const url = `https://picsart.com/ai-playground?aistate=${payload}`

With media inputs

const payload = encodeDeepLinkPayload('kling-avatar', {
  prompt: 'Character speaking to camera',
  imageUrls: ['https://cdn.picsart.com/portrait.png'],
  audioUrl: 'https://cdn.picsart.com/voiceover.mp3',
})

Decode (read a payload)

import { decodeDeepLinkPayload } from '@picsart/ai-sdk'

const result = decodeDeepLinkPayload(encodedString)
result.modelId     // 'veo-3.1'
result.context     // { prompt: '...', aspectRatio: '9:16' }
result.modelKnown  // true (model exists in catalog)
result.warnings   // [] (e.g. rejected URLs, unknown model)

API reference

FunctionReturnsDescription
encodeDeepLinkPayload(modelId, context)stringCompressed payload string
decodeDeepLinkPayload(encoded)DeepLinkResult | nullDecode payload string
🔒

Security: Prompts are sanitized (HTML/script tags stripped). Media URLs are validated against a CDN allowlist — data:, blob:, and external domains are rejected. Unknown models decode with a warning.

Advanced Usage

Auto-save to Picsart Drive

Pass a drive config when creating the client. Every generation will automatically save to that folder.

const ai = createClient({
  fetch: myAuthenticatedFetch,
  apiUrl: 'https://api.picsart.com',
  drive: { folder: 'My AI Creations' },
})

const result = await ai.generate(Models.Flux2Pro, {
  prompt: 'a painting of a sunset',
})

// File is now saved in your Drive!
console.log(result.drive.uid)  // the Drive file ID
Track progress for long generations

Video generation can take time. Use submit + subscribe to track progress live:

// Submit without waiting
const handle = await ai.submit(Models.KlingV3Pro, {
  prompt: 'a timelapse of a city skyline',
})

// Watch progress updates
for await (const update of ai.subscribe(handle)) {
  console.log(update.status)  // "processing", "completed", etc.
}

// Get the final result
const result = await ai.result(handle, Models.KlingV3Pro)
Cancel a running generation 
const handle = await ai.submit(Models.Sora2, {
  prompt: 'actually, never mind',
})

// Changed your mind? Cancel it.
await ai.cancel(handle)
Validate inputs before sending

Check if your parameters are valid for a model before making the API call:

const check = Models.validate(Models.Flux2Pro, {
  prompt: 'hello',
  aspectRatio: '99:1',  // invalid!
})

if (!check.valid) {
  console.log(check.errors)  // → ["aspectRatio: invalid option '99:1'"]
}
Get the JSON schema for a model

Useful for building dynamic forms or integrating with other tools:

const schema = Models.toSchema(Models.Flux2Pro)
console.log(JSON.stringify(schema, null, 2))
